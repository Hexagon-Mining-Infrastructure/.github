# Security Policy

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request for security problems.**

- Use GitHub's **private vulnerability reporting** on the affected repository
  (*Security → Report a vulnerability*), or
- Contact the Hexagon Mining Infrastructure platform team through the internal security channel.

Please include the affected repository, a description, impact, and steps to reproduce.
We aim to acknowledge reports within **2 working days** and agree a remediation timeline after triage.

## Leaked credentials

If you have committed or exposed a secret:

1. **Revoke / rotate it immediately** — assume it is compromised.
2. Report it as above, even if you've already rotated it.
3. Work with the platform team to purge it from history if required.

## Supported versions

Only the latest released major version of each module receives security fixes unless stated
otherwise in the repository.
