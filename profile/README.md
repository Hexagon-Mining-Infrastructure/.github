# Hexagon Mining Infrastructure

Home of the **Hexagon Mining Deployment Platform**: the infrastructure-as-code, platform
tooling and engineering knowledge behind Hexagon Mining's deployments.

> **New here?** Read the [Engineering Best Practices](https://github.com/Hexagon-Mining-Infrastructure/.github/blob/main/docs/best-practices/README.md)
> and the `README.md` of the repository you're working in.

---

## How we work

- **Everything as code.** No manual changes; every change goes through a pull request.
- **Small, layered building blocks.** Generic, reusable components are composed into deployments.
- **Conventional Commits, signed.** `type(scope): subject`, GPG-signed with a DCO `Signed-off-by` trailer.
- **Pinned versions.** Every dependency is pinned. No floating refs.
- **Shift-left quality.** Linting, security and secret scanning run locally *and* in CI.
